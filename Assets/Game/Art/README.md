# Art — 공통 시각 자원

## 다음 작업자용 빠른 안내

- 쉬운 이름: 공통 시각 자원.
- 수정 시작점: [README.md](README.md).
- 현재 담당: 모델·재질·텍스처·애니메이션·VFX 자료 관리.
- 이 폴더만으로 처리하지 않는 범위: 게임 판정·최종 외형 자동 확정.
- 함께 확인: Player, Levels, Core.
- 지시 예시: “슬라임 파츠 자원 위치 확인 → Art → README.md → Player, Levels, Core와 영향 확인”.
- 아래 상세 기획은 목표 책임, 날짜가 있는 구현·검사 기록은 해당 시점의 이력이다. 코드 존재와 정상 동작·서비스 연결 완료를 구분한다.

여러 기능·지역에서 함께 사용하는 모델·재질·텍스처·애니메이션·시각 효과를 둡니다. 특정 기능이나 챕터에서만 쓰는 자원은 해당 폴더에 둘 수 있으며, 같은 원본을 중복 관리하지 않습니다. 자원이 추가되면 제작 원본 위치와 사용처를 기록합니다.
