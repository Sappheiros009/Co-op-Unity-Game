# Art — 공통 시각 자원

여러 기능·지역에서 함께 사용하는 모델·재질·텍스처·애니메이션·시각 효과를 둡니다. 특정 기능이나 챕터에서만 쓰는 자원은 해당 폴더에 둘 수 있으며, 같은 원본을 중복 관리하지 않습니다. 자원이 추가되면 제작 원본 위치와 사용처를 기록합니다.
