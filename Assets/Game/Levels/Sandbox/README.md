# Sandbox — 시험 공간

이동·벽 타기·구조·장치·몬스터·맵 생성 등을 작게 재현하는 시험 씬이 추가될 위치입니다. 버그 기록에 재현 씬과 조건을 연결합니다. 현재 시험 씬은 없습니다.
