# Shared — 지역 공통 구성물

여러 지역에서 재사용하는 방·통로·환경 구성과 공통 배치 프리팹을 둡니다. 특정 챕터에서만 사용하는 콘텐츠는 해당 챕터에 둡니다. 장치의 동작 규칙은 Puzzles에서 관리합니다.
