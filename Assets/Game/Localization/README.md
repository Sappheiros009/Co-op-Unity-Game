# Localization — 언어와 폰트

## 다음 작업자용 빠른 안내

- 쉬운 이름: 언어와 폰트.
- 수정 시작점: [README.md](README.md).
- 현재 담당: 언어·글꼴 자료의 담당 안내.
- 이 폴더만으로 처리하지 않는 범위: 현재 모든 문장이 이 폴더로 분리된 것은 아님; 화면 배치는 UI.
- 함께 확인: UI, Story.
- 지시 예시: “한글 누락과 문장 잘림 → Localization → README.md → UI, Story와 영향 확인”.
- 아래 상세 기획은 목표 책임, 날짜가 있는 구현·검사 기록은 해당 시점의 이력이다. 코드 존재와 정상 동작·서비스 연결 완료를 구분한다.

언어별 문장, 글꼴과 언어 설정 자료를 관리합니다. Story는 사건과 대사 사용 조건, UI는 실제 배치와 잘림을 담당합니다. 텍스트가 추가되면 원문·언어·사용 화면을 연결합니다.
