# DESIGN-0003 — 인게임 품질 프리셋 및 저사양 성능 설정

문서 ID: DESIGN-0003 · 버전: 0.1 · 2026-09-18 · AI 추천·사용자 확인 대기  
담당: UI · Art · Core · Levels · Online 연계

## 목적

인게임 설정창에서 사용자가 자신의 PC에 맞는 품질 프리셋을 선택하고, 판타지 이세계풍의 시각적 방향을 유지하면서도 저사양 PC에서 렉과 프레임 저하를 줄이는 것을 목표로 한다.

이 문서는 게임 규칙을 바꾸는 문서가 아니다. 품질 설정은 각 클라이언트의 로컬 화면·연출 품질만 바꾸며, 서버 판정·충돌·점수·출구·협동 조건·랭킹에는 영향을 주지 않는다.

## 사용자 요구와 전제

- 고퀄리티는 포토리얼리즘이 아니라 판타지 이세계풍 고품질 스타일라이즈드 아트로 해석한다.
- 고사양 PC만을 기준으로 제작하지 않고, 저사양에서도 안정적으로 플레이할 수 있는 품질 단계를 제공한다.
- 사용자는 게임 중 설정창을 열어 품질 프리셋을 선택할 수 있어야 한다.
- 낮은 품질에서도 몬스터·출구·퍼즐·위험 신호·상호작용 대상 등 게임플레이에 필요한 정보가 사라지면 안 된다.
- Unity 목표 버전은 `6000.6.1f1`이지만, 실제 패키지·렌더 파이프라인·최소 사양 호환성은 아직 검증하지 않았다.

## 프론트엔드 표현의 사용자 결정권

품질 기능의 기술적 동작은 AI가 추천할 수 있지만, 설정창이 플레이어에게 보이는 스타일은 사용자 최종 결정 항목이다.

- 패널·버튼·드롭다운의 시각 스타일, 색상, 장식, 폰트, 아이콘은 사용자 승인 전까지 후보안이다.
- 자동·낮음·중간·높음·사용자 지정이라는 이름과 설명도 사용자가 원하는 분위기와 용어에 맞춰 최종 확정한다.
- 품질을 낮췄을 때 사용할 대체 VFX·색·아이콘·사운드 표현은 사용자에게 변경 전후를 보여 주고 승인받는다.
- AI는 가독성·접근성·해상도 대응·성능 비용을 검토하지만, 그 검토 결과만으로 UI 스타일을 확정하지 않는다.

## AI 추천 기본안

### 추천 프리셋 구성

기본 화면에는 복잡한 개별 옵션을 모두 노출하지 않고 다음 5개 항목을 제공한다.

| 프리셋 | 기본 목적 | 추천 적용 방향 |
|---|---|---|
| 자동(권장) | PC 정보를 기준으로 안전한 품질을 선택 | 로컬 하드웨어 정보와 초기 측정 결과만 사용하고, 온라인 전송은 하지 않는다. |
| 낮음 | 저사양 PC에서 프레임 안정성 우선 | 1K 텍스처·강한 LOD·간소화된 그림자·최소 후처리·낮은 VFX 밀도 |
| 중간 | 품질과 성능의 균형 | 1K~2K 텍스처·중간 LOD·제한된 그림자·필수 후처리 |
| 높음 | 권장 사양에서 시각 품질 우선 | 핵심 에셋 2K·높은 LOD·선택적 그림자·선택적 VFX와 후처리 |
| 사용자 지정 | 세부 조정 | 고급 설정을 직접 조절하되, 게임플레이 가시성 보호 규칙은 변경할 수 없다. |

`매우 높음·울트라` 프리셋은 기본으로 만들지 않는다. 실제 고사양 사용자 수요와 프로파일링 결과가 확인된 뒤 별도 검토한다.

### 프리셋별 적용 기준 초안

아래 값은 에셋 제작과 수직 슬라이스를 위한 초기 목표다. 최소 사양과 목표 프레임을 측정한 뒤 확정한다.

| 설정 항목 | 낮음 | 중간 | 높음 | 사용자 지정에서의 제한 |
|---|---|---|---|---|
| 텍스처 | 일반 1K 중심 | 일반 1K, 핵심 2K 선택 | 핵심 캐릭터·보스·랜드마크 2K | 4K는 기본 비활성, 예외 승인 필요 |
| LOD | 빠른 단계 전환·먼 거리 단순화 | 표준 전환 | 근거리 디테일 유지 | LOD를 완전히 끄지 않음 |
| 그림자 | 비활성 또는 매우 낮음 | 제한된 실시간 그림자 | 핵심 광원 중심의 선택적 그림자 | 그림자 수·거리 상한 유지 |
| 조명·후처리 | 색 보정·필수 안개만 | 가벼운 볼륨과 색 보정 | 선택적 볼륨·발광·안개 | 화면 전체 효과의 상한 유지 |
| VFX | 파티클 수·광원·투명 면적 축소 | 표준 밀도 | 전용 보스·랜드마크 효과 허용 | 위험·출구·상호작용 신호는 항상 유지 |
| 환경 장식 | 거리 컬링·인스턴싱 적극 적용 | 표준 배치 | 가시 거리와 장식 밀도 증가 | 충돌·퍼즐·길찾기 대상은 제거하지 않음 |
| 반사·고급 셰이더 | 공용 저비용 재질 | 제한된 재질 효과 | 검증된 핵심 에셋만 사용 | 실시간 반사·고급 산란은 기본 비활성 |
| 애니메이션 | 게임플레이 동작은 동일, 장식 효과 축소 | 표준 | 장식 동작 허용 | 이동·상호작용·위험 전달 동작은 낮추지 않음 |
| 해상도·렌더 스케일 | 저사양 안전값 | 기본값 | 높은 렌더 스케일 | 최소 렌더 스케일 하한을 둠 |

### 품질과 게임플레이 공정성 분리

품질 설정으로 다음 항목을 줄이거나 제거할 수 없다.

- 플레이어·몬스터·보스의 충돌체와 실제 판정
- 출구·퍼즐·상호작용 대상의 존재 여부
- 위험 구역·발판 상태 변화·몬스터 인식·추격 예고의 핵심 표시
- 구조·부활·출구 집계·점수·랭킹에 필요한 UI와 이벤트
- 네트워크 동기화 상태와 서버가 결정한 결과

낮은 품질에서는 같은 정보를 더 단순한 색·아이콘·발광·저비용 파티클로 표현한다. 오브젝트를 숨겨 난이도나 경쟁 결과가 달라지는 방식은 허용하지 않는다.

## 추천 UI 구조

현재 Unity 씬·Prefab·UI Toolkit 파일이 없으므로, 새 런타임 설정창은 **uGUI(Canvas 기반)**를 우선 추천한다. 실제 구현 시 프로젝트가 다른 UI 시스템으로 확정되면 동작 규칙은 유지하고 표현 계층만 해당 시스템으로 옮긴다.

```text
SettingsCanvas
└─ SettingsPanel
   ├─ Header
   │  ├─ TitleText
   │  └─ CloseButton
   ├─ QualitySection
   │  ├─ QualityPresetLabel
   │  ├─ QualityPresetDropdown
   │  ├─ AutoDetectButton
   │  └─ QualitySummaryText
   ├─ AdvancedQualitySection
   │  ├─ TextureQualityRow
   │  ├─ ShadowQualityRow
   │  ├─ VfxQualityRow
   │  ├─ ViewDistanceRow
   │  └─ RenderScaleRow
   ├─ ApplyButton
   ├─ RevertButton
   └─ ResetToRecommendedButton
```

### UI 동작 규칙

- `QualityPresetDropdown`은 자동·낮음·중간·높음·사용자 지정만 표시한다.
- 자동 선택 결과는 사용자에게 “현재 적용될 품질”을 글자로 알려준다.
- 프리셋을 바꾼 뒤 즉시 영구 저장하지 않고, `ApplyButton`을 눌러야 적용·저장한다.
- `RevertButton`은 적용 전 변경을 취소한다.
- 문제가 발생하거나 적용에 실패하면 이전 설정으로 되돌린다.
- `ResetToRecommendedButton`은 자동 추천값을 불러오며, 최종 적용 전까지 미리보기 상태로 둔다.
- 모든 텍스트는 TextMeshPro를 사용하고, 저사양 설정에서도 UI 글자·중요 아이콘의 가독성을 낮추지 않는다.
- Canvas는 `CanvasScaler`의 `Scale With Screen Size`를 기본으로 검토하고, 화면 비율·언어 길이·해상도별 배치를 검사한다.
- 인터랙션 UI에는 정확히 하나의 EventSystem과 Canvas의 GraphicRaycaster가 필요하다.

## 설정 저장·네트워크 규칙

- 품질 설정은 개인 클라이언트 설정으로 저장한다.
- 캠페인 진행·해금·업적·점수·랭킹 저장과 분리한다.
- 품질 설정은 서버에 전송하지 않으며, 다른 플레이어의 품질 설정을 강제로 변경하지 않는다.
- 파티클·후처리·장식 애니메이션은 로컬에서 처리한다. 서버는 필요한 게임플레이 이벤트와 상태만 전달한다.
- 품질 낮춤으로 서버 판정·충돌·상호작용·점수 계산의 결과가 달라지지 않아야 한다.
- 설정 변경 중에도 온라인 세션·런·타이머·출구 집계가 초기화되지 않아야 한다.

## 성능 검증 계획

품질 프리셋은 메뉴가 표시되는 것만으로 완료로 보지 않는다. 다음 조건을 실제 Unity 플레이테스트에서 확인한다.

| 검증 항목 | 확인 내용 |
|---|---|
| 적용 | 설정창에서 프리셋을 바꾸고 실제 장면의 텍스처·LOD·그림자·VFX가 변경되는가 |
| 저장 | 게임을 재실행해도 선택한 설정이 유지되는가 |
| 복구 | 적용 실패·강제 종료·잘못된 설정에서 이전 설정으로 복구되는가 |
| 저사양 | 최소 사양 후보에서 프레임 시간 급증·긴 멈춤·메모리 부족이 발생하지 않는가 |
| 협동 | 2~4인과 몬스터·퍼즐·출구 VFX가 동시에 동작해도 품질별 게임플레이 판정이 동일한가 |
| 가시성 | 낮음에서도 플레이어·몬스터·출구·위험·상호작용 대상을 찾을 수 있는가 |
| 공정성 | 품질 변경으로 충돌체·판정·시야 악용·랭킹 이점이 생기지 않는가 |
| 해상도·언어 | 화면 비율·해상도·한국어 텍스트 길이에서 설정창이 잘리지 않는가 |

초기 성능 목표는 최소 사양 후보에서 안정적인 30 FPS를 우선 검토한다. 실제 수치는 PC 하드웨어 후보, 해상도, Unity 렌더 파이프라인, 장면별 프로파일링 결과를 확인한 뒤 확정한다.

## 현재 미정 사항

- 최소 사양·권장 사양·목표 해상도·목표 프레임

- 자동 추천 판정에 사용할 하드웨어 지표와 최초 측정 방법
