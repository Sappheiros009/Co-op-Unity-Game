# TASK-0017 — 테스트·버그·운영 기준 정리

상태: 문서·검사 도구 반영, 사용자 검증 대기. 2026-09-20.

## 목표

09 담당 범위에 테스트 판정값, 증거 보존, 버그 생명주기, 운영 사건·릴리스·복구 연결을 적용한다. 게임 규칙·UI 표현·네트워크 구조·출시 범위를 결정하지 않는다.

## 변경 범위

| 경로 | 변경 |
|---|---|
| `Docs/Testing` | 공통 판정·증거 기준, 테스트 기준서, 양식 보강, 기록 구조 검사 도구 |
| `Docs/Bugs` | 분류·재현 판정·해결 증거 기준 보강 |
| `Docs/Operations` | 사건·릴리스 상태, 장애·복구 런북 연결 |
| `Docs/Maintenance` | 담당 작업 목록과 본 작업 기록 연결 |
| `.github/workflows` | 기존 문서 검증 흐름에 09 기록 구조 검사 단계 연결 |

## 보존 경계

다른 담당 폴더의 소스·설정·기획 계약은 수정하지 않는다. 실제 기능 문제가 발견되면 해당 담당 채팅과 파일을 요구사항으로 연결한다. 외부 서비스·Unity 라이선스·Steam/PlayFab 자격증명은 사용하지 않는다.

## 미검증 범위

이 작업은 테스트·문서·CI 구조를 추가한 것이며, 최종 Unity 테스트 실행, 게임 동작, 온라인 서비스, 배포, 운영 복구 성공을 증명하지 않는다.
