# Operations — 운영과 복구

배포 버전의 장애·이용자 영향·긴급 수정·제재·복구를 기록한다. 실제 사건이 생기면 [사건 양식](INCIDENT_TEMPLATE.md)을 사용하고, 배포에는 [릴리스 양식](RELEASE_TEMPLATE.md)을 연결한다.

## 보안 운영

서버 검증에서 확인된 핵은 즉시 세션 추방한다. Steam Game Ban과 장기 계정 제한은 해당 Steam 계정과 검토된 증거를 기준으로 운영자가 결정한다. 단순 신고·지연·버그·IP·전화번호·PC 일치만으로 자동 영구 정지하지 않는다.

사건 번호, 계정·런 참조, 빌드·규칙 버전, 시각, 근거, 조치 범위·만료, 검토자, 이의제기·해제·기록 복구 결과를 연결한다. 게임 내 안내에는 이해할 수 있는 사유와 문의 경로를 제공한다. 실제 비공개 증거·개인정보는 공개 저장소에 저장하지 않는다.

방장 추방, 보안 추방, 채팅·음성 제한, Game Ban, 랭킹 무효화는 각각 관리한다. 정상 팀원을 연대 제재하지 않는다. 제재 기간·로그 보관·운영자 권한·처리기한은 [상태 문서](../PROJECT_STATE.md)의 상세 결정 대상이다.

## 기록 연결

버그의 재현과 원인은 [Bugs](../Bugs/README.md), 수정 작업은 [Maintenance](../Maintenance/README.md), 실제 검사 결과는 [Testing](../Testing/README.md)로 연결한다. 담당 폴더와 실제 수정 파일을 적는다.

현재 운영 서비스·제재 API·모니터링은 구현 전이다.
