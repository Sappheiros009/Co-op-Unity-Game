# 문서 게시 현황

기준일: 2026-09-17. 확정된 질문·선택지·답변을 읽기 쉬운 기획서로 전환하고 GitHub·Notion을 같은 기준으로 맞추는 개정이다.

## 개정 범위

- [통합 기획서](../Plan.md): 게임 흐름·조작·협동·출구·점수·콘텐츠·서버·운영.
- [출구와 팀 점수](DESIGN-0001-StageExit.md): 규칙·예외·검증 기준.
- [현재 상태](PROJECT_STATE.md): 미정 사항, 자료 간 충돌과 구현 확인 범위.
- [구조](ARCHITECTURE.md)·[파이프라인](PIPELINE.md)·[폴더 지도](FOLDER_MAP.md)·기능 README·검사 계약 동기화.
- [개발 협업 프롬프트](PROJECT_PROMPT.md): 사용자 원문 유지.

기존 main 이력을 이어서 갱신하며 강제 덮어쓰기를 하지 않는다. 게시 대상은 기획·관리 문서, 폴더 안내와 검사 코드다. 로컬 생성 리포트·로그·자격증명·개인정보는 제외한다.

[검증 결과](Testing/TEST-0001-PlanningPipeline.md)는 문서 검사와 실제 게임·보안·배포 검증을 구분한다. 원격 재조회 후 게시 상태를 갱신한다.
