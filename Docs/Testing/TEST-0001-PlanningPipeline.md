# TEST-0001 — 기획 검증 파이프라인

검증일: 2026-09-17. 대상: 서술형 기획서, 계약 schema 2, PowerShell 검사기, GitHub Actions 설정.

## 검증 범위

확정 계약 값·자료형, 지정 폴더명, 내부 문서 링크, 핵심 규칙 표기, 완료된 질문지 잔여물, PowerShell 구문과 CI의 제한된 보안 설정을 검사한다. 과거 원문 블록 해시 검사는 사용자 요청에 맞춰 서술형 기획 검사로 교체했다.

이는 Unity 컴파일·게임 실행·멀티플레이·Steam 연동·안티치트 효과·배포 검증이 아니다.

초기 검사에서 5초 규칙과 필수 표기 검사 사이의 문구 차이를 발견했다. 기획서에 '최대 5초'를 명시한 뒤 Validate 실패 0을 확인했다. 게임 규칙이나 미정 선택을 변경한 것은 아니다.

자기 테스트는 정상 기획, 예시 코드 안 링크 무시, 잘못된 링크·폴더·대소문자·JSON·규칙·자료형·버전, 질문지 재삽입, 서버 명칭 누락, 미정 네트워크 임의 확정, PowerShell 구문, 액션 버전 고정, CI 권한, 출시 차단을 검사한다.
