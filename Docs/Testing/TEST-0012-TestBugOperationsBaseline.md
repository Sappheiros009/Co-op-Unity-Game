# TEST-0012 — 테스트·버그·운영 기준

상태: 기준 문서. 실행된 테스트 결과가 아님.

## 목적

09 담당 폴더의 테스트 코드, 검증 기록, 버그, 유지보수 작업, 운영 사건과 릴리스 기록을 같은 증거 기준으로 연결한다. 이 문서는 게임 기능의 구현 완료나 출시 승인을 의미하지 않는다.

## 표준 판정

| 값 | 의미 | 허용 근거 |
|---|---|---|
| `PASS` | 지정 조건에서 실제 기대 결과 확인 | 같은 실행의 로그·JUnit·캡처·빌드 식별자 |
| `FAIL` | 기대 결과와 실제 결과 불일치 | 실패 로그와 재현 조건 |
| `BLOCKED` | 환경·권한·서비스·결정 미완료로 실행 불가 | 차단 원인과 필요한 조치 |
| `NOT_RUN` | 실행하지 않음 | 미실행 이유 |
| `NOT_APPLICABLE` | 대상 범위에 해당하지 않음 | 제외 근거 |

문서·코드 존재, 컴파일, 빌드 성공은 런타임·멀티플레이·배포 성공의 증거가 아니다. 이전 실행 결과를 새 커밋의 결과로 재사용하지 않는다.

## 테스트 층위

| 층위 | 확인 대상 | 금지된 확대 해석 |
|---|---|---|
| 정적 | 계약·경로·링크·PowerShell·CI 정책 | 게임 실행 성공 |
| EditMode/순수 모델 | 규칙·상태 전이·중복·저장 모델 | 실제 물리·네트워크 성공 |
| PlayMode | 씬·입력·충돌·화면 흐름 | 실제 이용자 완주 |
| 로컬 멀티프로세스 | 전용 서버·2~4인·권한·이탈 | PlayFab·WAN·Steam 성공 |
| 외부 서비스 | PlayFab·Steam·운영 계정 | 로컬 시험으로 대체 |
| 운영/출시 | 배포·복구·마이그레이션·오탐 | 계획 문서만으로 완료 |

현재 각 층위의 실제 범위는 개별 `TEST-번호` 기록과 [프로토타입 충족도](../PROTOTYPE_COVERAGE.md)를 따른다.

## 필수 기록

각 실행 기록에 다음 항목을 포함한다.

- 테스트 ID, 관련 TASK/BUG/INC/RELEASE
- 브랜치·커밋·Unity·패키지·데이터 버전
- 플랫폼·기기·언어·참가 인원·권한·네트워크 조건
- 사전조건·입력·기대 결과·실제 결과
- 로그·JUnit·캡처·빌드 해시·실행 식별자
- 판정값과 실패·차단·미실행 이유
- 적용 범위와 아직 확인하지 않은 범위

## 연결 규칙

테스트 실패는 [Bugs](../Bugs/README.md)의 재현 가능한 기록으로 연결한다. 수정은 [Maintenance](../Maintenance/README.md)의 실제 파일 기록으로 연결한다. 배포 후 영향은 [Operations](../Operations/README.md)의 사건·릴리스 기록으로 연결한다. 담당 범위를 벗어난 소스 변경은 해당 채팅의 요구사항으로 넘긴다.

문서 구조 검사: `pwsh -NoProfile -File ./Docs/Testing/Test-OperationalRecords.ps1`
